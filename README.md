What is the project?

A rhythm game from an idea I thought up and tried to make on Scratch several years ago.
I ultimately gave up because of Scratch's limitations, but now I have successfully brought this idea back from the dead into something I am genuinely proud of.



How did I built it?

Art: MSPaint and Krita
Code: All made in Godot
Music: From Creo, one of my favorite artists out there. all song links are on the itch,io page linked below.



How do you run it?

Opening it on the itch.io page of the game automatically runs it, so you can open it with this link if you haven't already:
https://rubester1233.itch.io/mouse-maneuverist
